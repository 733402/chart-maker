# chart-maker
chart maker

make pjsk chats in python 

installing
run
sudo apt-get update && sudo apt-get install -y ffmpeg && pip install librosa numpy
then run main.py song.mp3

rename song with the name of ur mp3 file
NOTE song must be in the same directory as main.py
